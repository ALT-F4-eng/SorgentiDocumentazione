\subsection{Componenti}
\label{subsec:Componenti}

\subsubsection{LLMListPage}
\textbf{Elementi chiave}
\begin{itemize}
    \item View LLMs: Contenitore che mostra i modelli LLM presenti nel sistema.
    \item Scroll Bar: Permette di scorrere verticalmente la lista dei modelli.  
    \item Select Button: Consente di selezionare un LLM dalla lista. 
    \item Delete Button: Permette di cancellare il LLM corrispondente.
    \item Link Button: Reindirizza alla pagina dedicata all'aggiunta di un nuovo LLM.
\end{itemize}

\subsubsection{LLMPage}
\textbf{Elementi chiave}
\begin{itemize}
    \item View Details: Contenitore che mostra tutte le informazioni relative al LLM selezionato.
    \item Config: Permette di accedere alla configurazione e modificare le impostazioni del LLM selezionato.
    \item Form: Form in cui l’utente può inserire le informazioni necessarie.
    \item Save Button: Consente di salvare le modifiche effettuate.
    \item Add Button: Aggiunta di un nuovo LLM.
\end{itemize}
