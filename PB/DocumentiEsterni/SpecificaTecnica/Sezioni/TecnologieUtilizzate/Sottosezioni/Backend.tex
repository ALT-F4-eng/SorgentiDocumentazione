\subsubsection{Python}
\label{subsubsec:Python}
\glossario{Python} è un linguaggio di programmazione ad alto livello ed è considerato il riferimento principale per l'intelligenza artificiale e il machine learning.\\  

\textbf{Motivazioni:}  

\begin{enumerate}
    \item \textbf{LLM}: è il linguaggio più utilizzato per interagire con modelli di linguaggio di grandi dimensioni.
    \item \textbf{Librerie}: dispone di una vasta gamma di librerie e moduli di terze parti che semplificano lo sviluppo di applicazioni.
    \item \textbf{Orientato agli oggetti}: supporta la programmazione orientata agli oggetti, consentendo di organizzare il codice in modo modulare e aderente ai principi \glossario{SOLID}.
    \item \textbf{Dinamicamente tipizzato}: offre flessibilità e rapidità di sviluppo, permettendo di assegnare variabili senza dichiararne esplicitamente il tipo.
    \item \textbf{Gestione eccezioni}: permette di intercettare e gestire errori in fase di esecuzione, migliorando la robustezza del codice.
    \item \textbf{Comunità}: una vasta comunità di sviluppatori garantisce supporto continuo, aggiornamenti e soluzioni ai problemi più comuni.
\end{enumerate}

\subsubsection{Flask}
\label{subsubsec:Flask}
Flask è un micro-framework per la creazione di API e applicazioni web in Python.

\textbf{Motivazioni:}

\begin{enumerate}
    \item \textbf{Leggerezza e semplicità}: Flask è un framework minimalista che fornisce solo gli strumenti essenziali per lo sviluppo web, lasciando agli sviluppatori la libertà di scegliere librerie e strumenti aggiuntivi;
    \item \textbf{Flessibilità}: Non impone una struttura rigida, permettendo di organizzare il codice in modo personalizzato e adattandolo alle necessità del progetto;
    \item \textbf{Modularità}: Flask permette di organizzare il codice in Blueprints, facilitando la suddivisione di un'app in moduli più gestibili e scalabili;
    \item \textbf{Ecosistema esteso}: Grazie alla sua popolarità, esiste un vasto ecosistema di estensioni disponibili per aggiungere funzionalità come autenticazione, gestione del database e gestione delle sessioni;
    \item \textbf{Facilità di apprendimento}: La curva di apprendimento è molto bassa, rendendolo ideale per sviluppatori alle prime armi con lo sviluppo web in Python;
    \item \textbf{Compatibilità}: Può essere facilmente integrato con ORM come SQLAlchemy;
    \item \textbf{Testabilità}: Flask include strumenti per il testing delle API, semplificando il testing del codice;
    \item \textbf{Controllo completo}: A differenza di framework più strutturati come Django, Flask offre agli sviluppatori un controllo totale su routing, gestione delle richieste e configurazione del progetto.
\end{enumerate}
