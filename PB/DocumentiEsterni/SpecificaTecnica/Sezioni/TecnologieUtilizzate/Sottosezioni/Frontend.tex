\subsubsection{Angular}
\label{subsubsec:angular}
Angular è un framework open source scritto in Typescript per lo sviluppo di Single-Page Application SPA.\\
\textbf{Motivazioni}
\begin{enumerate}
    \item \textbf{Basato su componenti}: impone una suddivisione modulare dell'applicazione in componenti, ciascuno composto da tre parti principali: logica (classe TypeScript), interfaccia (HTML) e stile (CSS);  
    
    \item \textbf{Dependency Injection}: offre un'implementazione integrata del pattern Dependency Injection, permettendo di iniettare servizi nei componenti demandando al framework l'onere della loro costruzione;
    
    \item \textbf{Reattività}: grazie ai meccanismi di event binding e property binding, consente di reagire alle interazioni dell'utente e aggiornare dinamicamente l'interfaccia in base allo stato dell'applicazione;  
    
    \item \textbf{Pacchetti}: l'ecosistema di Angular include numerosi pacchetti che forniscono componenti e direttive aggiuntive per estendere le funzionalità dell'applicazione.  
    Questi pacchetti possono essere facilmente gestiti tramite la Angular CLI, un tool a riga di comando che semplifica la gestione dei progetti Angular;  
    
    \item \textbf{Routing}: Angular fornisce nativamente un servizio di routing che semplifica la gestione della navigazione nella SPA; 
    
    \item \textbf{TypeScript}: superset di JavaScript che introduce sintassi per supportare funzionalità aggiuntive quali: controllo dei tipi a tempo di compilazione, Interfacce e tipi generici.
    Il codice TypeScript viene poi compilato in JavaScript per essere eseguito nel browser client.
\end{enumerate}
