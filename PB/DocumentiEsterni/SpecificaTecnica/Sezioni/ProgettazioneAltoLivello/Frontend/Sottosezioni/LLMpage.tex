\subsubsection{LLMPage} 
\label{sec:LLMPage}
\paragraph{Descrizione}
LLMPage è il componente che si occupa di gestire la visualizzazione, l'inserimento e la modifica degli LLM salvati tramite le seguenti funzionalità:
\begin{itemize}
    \item Visualizzazione informazioni di un LLM salvato;
    \item Modifica delle informazioni d un LLM salvato;
    \item Compilazione delle informazioni associate a un nuovo LLM.
\end{itemize}

\paragraph{SottoComponenti}
LLMPage è composto dai seguenti sotto-componenti:
\begin{itemize}        
        \item \textbf{LLMForm}: componente utilizzato per la modifica di un LLM salvato e compilazione di un nuovo LLM;
        \item \textbf{LLMView}: componente che visualizza le informazioni di un LLM salvato.
    \end{itemize}
