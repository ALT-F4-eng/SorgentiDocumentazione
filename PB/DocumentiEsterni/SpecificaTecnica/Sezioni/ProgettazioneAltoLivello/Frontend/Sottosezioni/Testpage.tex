\subsubsection{TestPage}
\label{sec:TestPage}
\paragraph{Descrizione}
TestPage è il componete che mostra tutte le informazioni relative al test selezionato ed eseguito. Presenta le seguenti funzionalità:
\begin{itemize}
    \item Selezione di un test salvato per il confronto con il test corrente; 
    \item Visualizzazione del nome del test;
    \item Visualizzazione della data dell'esecuzione del test;
    \item Visualizzazione del diagramma di dispersione;
    \item Visualizzazione dell'indice riassuntivo;
    \item Visualizzazione delle domande, delle risposte attese, delle risposte ricevute, valore di similarità, valore booleano di correttezza.
\end{itemize}
\paragraph{SottoComponenti}
TestPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{ScatterDiagram}: diagramma di dispersione;
    \item \textbf{CakeDiagram}: diagramma a torta;
    \item \textbf{BarDiagram}: diagramma a barre;
    \item \textbf{QATestListView}: lista scorrevole che mostra tutte le domande, le risposte attese, le risposte ricevute dal LLM, valore di similarità, valore booleano di correttezza.
\end{itemize}
