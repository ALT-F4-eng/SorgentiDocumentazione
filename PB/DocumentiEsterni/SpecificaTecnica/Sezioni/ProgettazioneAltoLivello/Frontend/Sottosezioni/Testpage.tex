\subsubsection{TestPage}
\label{sec:TestPage}
\paragraph{Descrizione}
TestPage è il componente che mostra tutte le informazioni relative al test selezionato ed eseguito. Presenta le seguenti funzionalità:
\begin{itemize}
    \item Selezione di un test salvato per il confronto con il test corrente; 
    \item Visualizzazione delle nome del test;
    \item Visualizzazione della data dell'esecuzione del test;
    \item Visualizzazione del diagramma di dispersione;
    \item Visualizzazione dell'indice riassuntivo;
    \item Visualizzazione paginata dei risultati.
\end{itemize}
\paragraph{SottoComponenti}
TestPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{TestIndex}: indice riassuntivo del test che contiene i sotto-componenti:
    \begin{itemize}
        \item \textbf{CakeDiagram} diagramma a torta che rappresenta la percentuale di risposte corrette;
        \item \textbf{BarDiagram} diagramma a barre sulla distribuzione di frequenza dei gradi di similarità.
    \end{itemize}  
    
    \item \textbf{TestPageView}: contiene i seguenti sotto-componenti necessari a visualizzare in modo paginato i risultati del test:
    \begin{itemize}
        \item \textbf{ScatterDiagram}: diagramma di dispersione per i risultati appartenenti alla pagina visualizzata;
        
        \item \textbf{ResultListView}: lista dei risultati del test appartenenti alla pagina visualizzata composta dal seguente sotto-componente: \textbf{ResultElement};
        
        \item \textbf{PageNavigation}: permette la navigazione tra le pagine del test.
    \end{itemize}
    \item \textbf{TestNameForm}: form che permette di assegnare un nome al salvataggio del test caricato;
    \item \textbf{TestSelectionComparison}: permette di selezionare un test salvato con cui eseguire il confronto con il test attualmente visualizzato.
\end{itemize}
