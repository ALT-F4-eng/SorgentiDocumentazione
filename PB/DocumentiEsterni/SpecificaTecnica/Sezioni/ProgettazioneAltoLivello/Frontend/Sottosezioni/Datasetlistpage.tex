\subsubsection{DatasetListPage}
\label{sec:DatasetListPage}
\paragraph{Descrizione}
DatasetPage è il componete che mostra le informazioni riguardanti tutti i dataset salvati. Presenta le seguenti funzionalità:
\begin{itemize}
    \item Caricamento di un dataset salvato;
    \item Rinominazione di un dataset salvato;
    \item Eliminazione di un dataset salvato;
    \item Creazione di una copia di un dataset salvato;
    \item Ricerca di un dataset salvato;
    \item Creazione di un dataset temporaneo;
    \item Scorrimento della lista dei dataset salvati;
    \item Visualizzazione delle informazioni di un dataset.
\end{itemize}
\paragraph{SottoComponenti}
DatasetPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{SearchBar}: barra per la ricerca dei dataset;
    \item \textbf{ListView}: lista scorrevole dei dataset salvati. Contiene il sottocomponente: \textbf{DatasetElement}.
\end{itemize}
