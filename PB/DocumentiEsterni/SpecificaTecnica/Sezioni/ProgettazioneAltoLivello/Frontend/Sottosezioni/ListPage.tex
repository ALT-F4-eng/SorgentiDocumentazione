\subsubsection{ListPage} 
\label{sec:ListPage}
\paragraph{Descrizione}
La ListPage è il componente che funge da struttura del layout per ogni pagina con lista e barra di ricerca con le seguenti funzionalità:
\begin{itemize}
    \item ricercare nella lista.
    \item eliminare dalla lista.
    \item aggiungere alla lista.
\end{itemize}  
\paragraph{SottoComponenti}
ListPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{SearchBar}: componente per la ricerca e filtraggio nella lista;
    \item \textbf{ListView}: componente che consente la visualizzazione di vari elementi;
\end{itemize}
