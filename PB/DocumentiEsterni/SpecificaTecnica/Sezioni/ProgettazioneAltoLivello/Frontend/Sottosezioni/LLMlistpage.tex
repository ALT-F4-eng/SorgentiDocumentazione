\subsubsection{LLMListPage} 
\label{sec:LLMListPage}
\paragraph{Descrizione}
LLMListPage è il componente che si occupa di visualizzare la lista degli LLM salvati con le seguenti funzionalità:
\begin{itemize}
    \item Visualizzare la lista di tutti gli LLM salvati.
    \item Eliminazione LLM salvato.
    \item Aggiungere un LLM.
    \item Rinominazione di un LLM salvato.
\end{itemize} 
\paragraph{SottoComponenti}
LLMListPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{LLMList}: componente per la visualizzazione della lista. Contiene il sottocomponente: \textbf{LLMElement}.
    %\item \textbf{LLMShowListComponent}: Componente che si occupa di mostrare la lista degli LLM salvati.
    %\item \textbf{SenderReqComponent}: Componente che si occupa dell'esecuzione di chiamate HTTP.
    %\item \textbf{LLMsReqComponent}: Tale componente funge da wrapper per la chiamata HTTP di visualizzazione degli LLM salvati per la conversione del tipo ritornato dalla chiamata, in un tipo consono alla logica del componente LLMListPage.
    %\item \textbf{SelectReqComponent}: Tale componente funge da wrapper per la chiamata HTTP di selezione per la conversione del tipo ritornato dalla chiamata, in un tipo consono alla logica del componente LLMListPage.
    %\item \textbf{DeleteReqComponent}: Tale componente funge da wrapper per la chiamata HTTP di eliminazione per la conversione del tipo ritornato dalla chiamata, in un tipo consono alla logica del componente LLMListPage.
    %\item \textbf{DialogComponent}: Il componente che consente la visualizzazione della finestra di dialog.
\end{itemize}
