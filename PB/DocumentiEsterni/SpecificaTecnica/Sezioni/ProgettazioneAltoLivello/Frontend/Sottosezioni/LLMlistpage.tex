\subsubsection{LLMListPage} 
\label{sec:LLMListPage}
\paragraph{Descrizione}
LLMListPage è il componente che si occupa di visualizzare la lista degli LLM salvati con le seguenti funzionalità:
\begin{itemize}
    \item Visualizzare la lista di tutti gli LLM salvati;
    \item Eliminare un LLM salvato;
    \item Aggiungere un LLM;
    \item Visualizzare un LLM salvato.
\end{itemize} 
\paragraph{SottoComponenti}
LLMListPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{LLMList}: componente per la visualizzazione della lista. Contiene il sotto-componente \textbf{LLMElement}.
\end{itemize}
