\subsubsection{DatasetContentPage}
\label{sec:DatasetContentPage}
\paragraph{Descrizione}
DatasetContentPage è il componente che permette di visualizzare le coppie di domande-risposte del dataset selezionato. Presenta le seguenti funzionalità:
\begin{itemize}
    \item Paginazione del dataset;
    \item Scorrimento della lista di domande-risposte attese che compongono la pagina del dataset visualizzata;
    \item Modifica delle domande e risposte;
    \item Eliminazione di una coppia domanda-risposta;
    \item Salvataggio del dataset visualizzato;
    \item Ricerca delle domande e risposte tramite parole chiave;
    \item Aggiunta di una coppia domanda-risposta;
    \item Esecuzione di un test con un LLM;
    \item Visualizzazione delle informazioni generali del dataset.
\end{itemize}
\paragraph{SottoComponenti}
DatasetContentPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{SearchBar}: barra di ricerca per le domande e le risposte;
    \item \textbf{DatasetPageView}: componente che contiene i seguenti sotto-componenti necessari a visualizzare in modo paginato il dataset:
    \begin{itemize}
        \item \textbf{QAListView} lista scorrevole che mostra tutte le coppie domande-risposte appartenenti alla pagina visualizzate usando il componente \textbf{QAListElement};
        \item \textbf{PageNavigation} permette la navigazione tra le pagine del dataset.
    \end{itemize}
    \item \textbf{QAForm}: form che permette all'utente di inserire o modificare elementi del dataset;
    \item \textbf{DatasetNameForm}: form che permette di assegnare un nome durante il salvataggio del dataset;
    \item \textbf{LLMSelectionList}: permette la selezione dell'LLM salvato da utilizzare nel test.
\end{itemize}
