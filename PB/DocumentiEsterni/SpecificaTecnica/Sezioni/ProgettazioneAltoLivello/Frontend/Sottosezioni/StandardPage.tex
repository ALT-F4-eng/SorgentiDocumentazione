\subsubsection{StandardPage} 
\label{sec:StandardPage}
\paragraph{Descrizione}
La StandardPage è il componente che funge da struttura del layout che ogni pagina con le seguenti funzionalità:
\begin{itemize}
    \item Creazione di un messaggio di sistema.
    \item Avvio di un caricamento grafico.
\end{itemize}  
\paragraph{SottoComponenti}
StandardPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{MenuComponent}: componente condiviso dalle pagine della web app che permette la navigazione tra le varie pagine;
    \item \textbf{FooterComponent}: componente che contiene informazioni riguardanti i contatti e il copyright;
    \item \textbf{LoadingComponent}: Il componente che si occupa dell'avvio del caricamento grafico;
    \item \textbf{MessageComponent}: Tale componente gestisce l'apparizione di messaggi di sistema.
\end{itemize}
