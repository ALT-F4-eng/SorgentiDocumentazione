\subsubsection{StandardPage} 
\label{sec:StandardPage}
\paragraph{Descrizione}
Il componente StandardPage definisce la struttura di layout comune utilizzata da ogni pagina con le seguenti funzionalità:
\begin{itemize}
    \item Creazione di un messaggio di sistema;
    \item Avvio di un caricamento grafico.
\end{itemize}  
\paragraph{SottoComponenti}
StandardPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{MenuComponent}: permette la navigazione tra le varie pagine;
    \item \textbf{FooterComponent}: contiene informazioni riguardanti i contatti e il copyright;
    \item \textbf{LoadingComponent}: si occupa dell'avvio del caricamento grafico;
    \item \textbf{MessageComponent}: gestisce l'apparizione di messaggi di sistema;
    \item \textbf{ConfirmComponent}: gestisce la conferma di operazioni critiche.
\end{itemize}
