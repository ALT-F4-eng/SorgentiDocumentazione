\subsubsection{LLMPage}
\label{sec:LLMPage}
\paragraph{Descrizione}
LLMPage è la pagina che si occupa di rendere visibile le opzioni e informazioni necessarie creazione e modifica di un LLM.
\paragraph{SottoComponenti}
LLMPage è composto dai seguenti sotto-componenti:
\begin{itemize}
        \item \textbf{LLMComponent}: Il componente con dichiarati i metodi e parametri necessari alla creazione di una LLMPage tra i quali:
        \begin{itemize}
            \item \textbf{mode}: Parametro settato in fase di routing, da informazioni sull chiamata HTTP che ha chiamato il componente consentendo comportamenti specifici a seconda della chiamata; ciò consente ad un componente di poter gestire leggere variazioni di comportamento conservando la stessa logica di fondo. Tale parametro consente la differenziazione tra la funzione di modifica di un LLM e quella di aggiunta di un LLM.
            \item \textbf{fields}: Parametro che memorizza tutti le opzioni impostate durante la sessione in corso sulla pagina. 
            \item \textbf{modifyName()}: Metodo che salva in fields il vecchio e nuovo valore impostato per il campo nome.
            \item \textbf{modifyURL()}: Metodo che salva in fields il nuovo valore impostato per il campo URL.
            \item \textbf{modifyKeyQ()}: Metodo che salva in fields il nuovo valore impostato per il campo chiave-domanda.
            \item \textbf{modifyKeyA()}: Metodo che salva in fields il nuovo valore impostato per il campo chiave-risposta.
            \item \textbf{modifyKeyValueH()}: Metodo che salva in fields il nuovo valore impostato per il campo chiave-header.
            \item \textbf{modifyKeyValueB()}: Metodo che salva in fields il nuovo valore impostato per il campo chiave-body.
            \item \textbf{save()}: Metodo che va eseguire il salvataggio delle opzioni memorizzare in fields chiamando FieldReqComponent.
            \item \textbf{reset()}: Metodo che setta fields al valore di default.
        \end{itemize}   
        \item \textbf{FieldReqComponent}: Componente dotato del metodo sendReq() che eredita da SenderReqComponent, tale componente funge da wrapper per la chiamata HTTP di salvataggio per la conversione del tipo ritornato dalla chiamata, in un tipo consono alla logica del componente LLMComponent. E' presente il riferimento in LLMComponent.
    \end{itemize}
