\subsubsection{StandardPage}
\label{sec:StandardPage}
\paragraph{Descrizione}
La StandardPage è la pagina che funge da struttura del layout che ogni pagina riceve come parametro con il nome del componente BasePageComponent.
\paragraph{SottoComponenti}
StandardPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{BasePageComponent}: Il componente che consente la creazione di una StandardPage con le seguenti funzionalità:
    \begin{itemize}
        \item Creazione dell'header.
        \item Creazione del footer.
        \item Creazione di un messaggio di sistema.
        \item Avvio di un caricamento grafico.
    \end{itemize}  
    \item \textbf{ObserverComponent}: Componente dotato dei metodi necessari al pattern Observer.
    \item \textbf{SubjectComponent}: Componente dotato dei metodi necessari al pattern Observer.
    \item \textbf{NavigationLinksComponent}: Componente che eredita da ObserverComponent, tale componente si occupa di aggiornare i link presenti sull header a seconda della pagina richiesta.
    \item \textbf{HeaderComponent}: Componente che eredita da SubjectComponent, tale componente riceve le modifiche richieste dal NavigationLinksComponent per aggiornare l'header.
    \item \textbf{FooterComponent}: Componente che instanzia il footer.
    \item \textbf{LoadingComponent}: Il componente che si occupa dell'avvio del caricamento grafico:
    \item \textbf{MessageHandlerComponent}: Componente che eredita da ObserverComponent, tale componente si occupa di creare il tipo e contenuto del messaggio.
    \item \textbf{MessageComponent}: Componente che eredita da SubjectComponent, tale componente riceve le impostazioni del messaggio richieste dal MessageHandlerComponent per aggiornare l'apparizione del messaggio.
\end{itemize}


\subsubsection{LLMListPage}
\label{sec:LLMListPage}
\paragraph{Descrizione}
LLMListPage è la pagina che si occupa di mostrare la lista degli LLM salvati.
\paragraph{SottoComponenti}
LLMListPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{LLMListComponent}: Il componente con dichiarati i metodi e parametri necessari alla creazione di una LLMListPage con le seguenti funzionalità:
    \begin{itemize}
        \item comportamento modulabile in fase di routing a seconda della chiamata HTTP, consentendo comportamenti specifici a seconda della chiamata; ciò consente ad un componente di poter gestire leggere variazioni di comportamento conservando la stessa logica di fondo. Tale parametro consente la differenziazione tra la funzione di visualizzare gli LLM e quella di visualizzare gli LLM in fase di test.
        \item Mostrare la lista di tutti gli LLM salvati.
        \item Reindirizzamento alla pagina dedita all'avvio del test con le informazione sul LLM selezionato.
        \item Eliminazione LLM salvato.
        \item Salvataggio un LLM. 
        \item Gestione per la conferma di azioni che comporteranno modifiche significative.
    \end{itemize}   
    \item \textbf{SenderReqComponent}: Componente che si occupa dell'esecuzione di chiamate HTTP.
    \item \textbf{SelectReqComponent}: Componente che eredita da SenderReqComponent, tale componente funge da wrapper per la chiamata HTTP di selezione per la conversione del tipo ritornato dalla chiamata, in un tipo consono alla logica del componente LLMListComponent. E' presente il riferimento in LLMListComponent.
    \item \textbf{DeleteReqComponent}: Componente che eredita da SenderReqComponent, tale componente funge da wrapper per la chiamata HTTP di eliminazione per la conversione del tipo ritornato dalla chiamata, in un tipo consono alla logica del componente LLMListComponent. E' presente il riferimento in LLMListComponent.
    \item \textbf{DialogComponent}: Il componente che consente la visualizzazione della finestra di dialog.
    \item \textbf{CommandComponent}: Componente dotato dei metodi necessari al pattern Command.
    \item \textbf{ContinueEventComponent}: Componente dotato dei metodi necessari al pattern Command che inoltra la richiesta con DeleteReqComponent.
    \item \textbf{CancelEventComponent}: Componente dotato dei metodi necessari al pattern Command che interrompe l'azione principale.
    \item \textbf{EventsHandlerConfirmationComponent}: Componente che eredita da CommandComponent, tale componente esegue l'azione del ContinueEventComponent.
    \item \textbf{EventsHandlerAnnullationComponent}: Componente che eredita da CommandComponent, tale componente esegue l'azione del CancelEventComponent.
\end{itemize}

\subsubsection{LLMDetailsPage}
\label{sec:LLMDetailsPage}
\paragraph{Descrizione}
LLMDetailsPage è la pagina che si occupa di rendere visibile le opzioni e informazioni relative ad un LLM.
\paragraph{SottoComponenti}
LLMDetailsPage è composto dai seguenti sotto-componenti:
\begin{itemize}
        \item \textbf{LLMDetailsComponent}: Il componente che consente l'acquisizione delle informazioni sull' LLM.
        \begin{itemize}
            \item Visualizzazione del nome dell'LLM.
            \item Visualizzazione della data dell'ultima modifica.
            \item Visualizzazione del URL dell'LLM.
            \item Visualizzazione del nome dell'LLM.
            \item Visualizzazione delle coppie chiave-valore per la costruzione dell'header.
            \item Visualizzazione delle coppie chiave-valore per la costruzione del body.
            \item Visualizzazione della chiave relativa alla domanda da porre all'LLM.
            \item Visualizzazione della chiave relativa alla risposta data dall'LLM.
        \end{itemize} 
        \item \textbf{DetailsReqComponent}: Componente che eredita da SenderReqComponent, tale componente funge da wrapper per la chiamata HTTP di acquisizione dei dettagli per la conversione del tipo ritornato dalla chiamata, in un tipo consono alla logica del componente LLMDetailsComponent.
