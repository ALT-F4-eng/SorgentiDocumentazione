\subsubsection{DatasetListPage}
\label{sec:DatasetListPage}
\paragraph{Descrizione}
DatasetPage è il componete che mostra le informazioni riguardanti tutti i dataset, sia salvati che temporanei. Presenta le seguenti funzionalità:
\begin{itemize}
    \item Caricamento di un dataset salvato;
    \item Rinominazione di un dataset salvato;
    \item Eliminazione di un dataset salvato;
    \item Creazione di una copia di un dataset salvato;
    \item Ricerca di un dataset salvato;
    \item Creazione di un dataset temporaneo;
    \item Scorrimento della lista dei dataset salvati;
    \item Visualizzazione delle informazioni di un dataset.
\end{itemize}
\paragraph{SottoComponenti}
DatasetPage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{CreaDatasetBtn}: pulsante per la creazione di un dataset temporaneo;
    \item \textbf{UploadBtn}: pulsante per il caricamento di un dataset salvato in formato JSON;
    \item \textbf{SearchDatasetBar}: barra per la ricerca dei dataset;
    \item \textbf{DatasetListView}: lista scorrevole dei dataset sia salvati che temporanei, che comprende:
    \begin{itemize}
        \item \textbf{DatasetSelectBtn}: pulsante per selezionare un dataset presente nella lista;
        \item \textbf{DatasetChangeBtn}: pulsante per modificare il nome del dataset selezionato;
        \item \textbf{DatasetDeleteBtn}: pulsante per eliminare il dataset selezionato;
        \item \textbf{DatasetCopiaBtn}: pulsante per creare una copia del dataset selezionato;
        \item \textbf{DatasetInfoText}: pulsante per visualizzare le informazioni relative al dataset selezionato.
    \end{itemize}
\end{itemize}
