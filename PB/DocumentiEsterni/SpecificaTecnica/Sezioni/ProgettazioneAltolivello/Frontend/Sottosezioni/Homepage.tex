\subsubsection{HomePage}
\paragraph{Descrizione}
HomePage è il componente che guida l'utente nelle altre pagine web.
\paragraph{SottoComponenti}
HomePage è composto dai seguenti sotto-componenti:
\begin{itemize}
    \item \textbf{MenuComponent}: componente condiviso dalle pagine della web app che permette la navigazione tra le varie pagine e che comprende \textbf{LogoComponent} (logo della web app);
    \item \textbf{ContentComponent}: componente che descrive il progetto e le funzionalità della web app;
    \item \textbf{FooterComponent}: componente che contiene informazioni riguardanti i contatti e il copyright.
\end{itemize}
