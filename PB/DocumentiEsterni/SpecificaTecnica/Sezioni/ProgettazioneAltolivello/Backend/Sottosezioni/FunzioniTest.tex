\subsection{Funzioni Test}
\label{subsec:TestRequests}

\subsubsection{run\_test}  
\label{subsubsec:runtest}

\paragraph{Descrizione}  
La funzione \textbf{run\_test} utilizza le domande del dataset per valutare il modello LLM selezionato, restituendo i risultati e le relative statistiche in formato strutturato.


\paragraph{Dettagli dell'endpoint}
\begin{itemize}
    \item \textbf{HTTP Method}: POST
    \item \textbf{Endpoint}: \texttt{/test}
    \item \textbf{Response Format}: TestResponseDto
    \item \textbf{Dependency Injection}: \texttt{dataset\_service (DatasetService)} risolto tramite il container delle dipendenze (\texttt{Container.api.dataset\_service}). 
    \item \textbf{Decoratori usati}: \texttt{@api.route}
\end{itemize}

\paragraph{Parametri di input}
\begin{itemize}
    \item \textbf{questions (list)}: la lista di domande da utilizzare per il test;
    \item \textbf{url (str)}: URL del modello LLM da utilizzare per la valutazione;
\end{itemize}

\paragraph{Funzionamento}
\begin{itemize}
    \item Verifica la presenza dei dati nella richiesta e li valida;
    \item Esegue la funzione di valutazione passando le domande al modello LLM selezionato;
    \item Confronta le risposte generate con quelle corrette e calcola i punteggi;
    \item Restituisce un oggetto TestResponseDto contenente le risposte del modello, le valutazioni e i dati statistici.
\end{itemize}

\subsubsection{get\_test\_results}
\label{subsubsec:gettestresults}

\paragraph{Descrizione}
La funzione \textbf{get\_test\_results} consente di recuperare i risultati di un test precedentemente eseguito, fornendo un riepilogo delle valutazioni e dei punteggi.

\paragraph{Dettagli dell'endpoint}
\begin{itemize}
    \item \textbf{HTTP Method}: GET
    \item \textbf{Endpoint}: \texttt{/test}
    \item \textbf{Response Format}: TestResponseDto
    \item \textbf{Dependency Injection}: \texttt{test\_service (TestService)} risolto tramite il container delle dipendenze (\texttt{Container.api.test\_service}).
    \item \textbf{Decoratori usati}: \texttt{@api.route}
\end{itemize}

\paragraph{Parametri di input}
\begin{itemize}
    \item \textbf{dataset (str)}: nome del dataset di cui si vuole recuperare il test coi risultati;
    \item \textbf{testname (str)}: nome del test di cui si vogliono recuperare i risultati;
\end{itemize}

\paragraph{Funzionamento}
\begin{itemize}
    \item Verifica la presenza del dataset e del test specificato;
    \item Recupera i risultati del test associati al dataset;
    \item Restituisce un oggetto \texttt{TestResponseDto} contenente i dettagli dei risultati, inclusi i punteggi e le valutazioni;
\end{itemize}

\subsubsection{save\_test\_results}
\label{subsubsec:savetestresults}

\paragraph{Descrizione}
La funzione \textbf{save\_test\_results} salva i risultati del test in un file JSON, consentendo di mantenere traccia delle valutazioni e dei punteggi ottenuti.

\paragraph{Dettagli dell'endpoint}
\begin{itemize}
    \item \textbf{HTTP Method}: POST
    \item \textbf{Endpoint}: \texttt{/test}
    \item \textbf{Response Format}: TestResponseDto
    \item \textbf{Dependency Injection}: \texttt{test\_service (TestService)} risolto tramite il container delle dipendenze (\texttt{Container.api.test\_service}).
    \item \textbf{Decoratori usati}: \texttt{@api.route}
\end{itemize}

\paragraph{Parametri di input}
\begin{itemize}
    \item \textbf{results}: oggetto contenente i risultati del test da salvare;
    \item \textbf{filename (str)} (opzionale): nome del file da assegnare al salvataggio.
\end{itemize}

\paragraph{Funzionamento}
\begin{itemize}
    \item Verifica la presenza dei dati nella richiesta e ne valida il formato;
    \item Converte i risultati del test in formato JSON;
    \item Salva i dati in un file, utilizzando il nome fornito o un nome generato automaticamente;
    \item Restituisce un oggetto \texttt{SaveResponseDto} contenente l'esito del salvataggio e il percorso del file creato;
    \item Se il file esiste già, viene chiesta conferma all'utente per la sovrascrittura.
\end{itemize}

\subsubsection{compare\_test\_results}
\label{subsubsec:comparetestresults}

\paragraph{Descrizione}
La funzione \textbf{compare\_test\_results} consente di confrontare i risultati di due test eseguiti, evidenziando le differenze e le somiglianze tra di essi.

\paragraph{Dettagli dell'endpoint}
\begin{itemize}
    \item \textbf{HTTP Method}: POST
    \item \textbf{Endpoint}: \texttt{/test}
    \item \textbf{Response Format}: TestResponseDto
    \item \textbf{Dependency Injection}: \texttt{test\_service (TestService)} risolto tramite il container delle dipendenze (\texttt{Container.api.test\_service}).
    \item \textbf{Decoratori usati}: \texttt{@api.route}
\end{itemize}

\paragraph{Parametri di input}
\begin{itemize}
    \item \textbf{testname (str)}: nome del primo test da confrontare;
    \item \textbf{testname (str)}: nome del secondo test da confrontare;
\end{itemize}

\paragraph{Funzionamento}
\begin{itemize}
    \item Verifica la presenza dei test specificati;
    \item Recupera i risultati di entrambi i test;
    \item Confronta i risultati e genera un report delle differenze e somiglianze;
    \item Restituisce un oggetto \texttt{TestResponseDto} contenente i dettagli del confronto, inclusi i punteggi e le valutazioni;
\end{itemize}
